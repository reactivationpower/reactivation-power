# Patient Pipeline — Set Up Your First Campaign

## Director's treatment
- **Format:** 16:9, 7:00 (420 seconds). Standalone beginner tutorial, separate from the four-minute product walkthrough.
- **Promise:** A first campaign is ready only after an actual form submission reaches the correct campaign; saving the offer is not the connection.
- **Identity:** Official Patient Pipeline logo, navy #092a3b, teal #0b8f89, warm cream #f8f5ed, Space Grotesk / DM Sans. Matilda narrates over restrained instrumental music.
- **Hero:** Actual seeded-demo Patient Pipeline screens. Editorial chapter cards and restrained callouts orient the viewer; they are not represented as product UI. Browser-only staging removes demo identifiers and masks the private connection address. No external Zapier or Facebook UI is simulated.
- **Motion:** Section-number handoffs, gentle screen pushes and UI-state cuts, and a thin teal rule connecting successive steps. Plenty of readable screen time; the visual changes through screen steps rather than ambient decoration.
- **Arc:** Preparation → campaign/offer → form source → external connector handoff → real-form test → practice → lead queue → honest readiness checklist. The ending replaces the process rail with a clear completion criterion, not a claim of completion.
- **Claim boundary:** This demo does not have an authorized Facebook/Zapier test connection. No received-status frame or real-form test result is portrayed. Any visible sample leads are preexisting seeded examples, not evidence that the newly created campaign has received a submission. Call Now opens a call screen and does not dial. The connection address is never printed in the finished frames.

## Shot script
All times are absolute. The compact domain footer `www.PatientPipeline.app` stays visible, except where an app screenshot already occupies that region. Full app frames are displayed intact; detail callouts are editorial overlays outside the screenshot. Narration is scripted below for Matilda. Music is low and continuous; no fabricated interaction sound is necessary. Each section's screen changes and label transitions occur at the marked cut points; the last seconds establish the next section's teal rule.

### 07 / 3:25–4:40 (75s) — Connect an Instant Form

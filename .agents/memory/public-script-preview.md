description: User-approved constraints for marketing demonstrations of the two calling products.

Public script previews must show two screens of the actual script, with actual response buttons and coaching notes. Only sample token values should be substituted.

**Why:** The user rejected invented preview responses that rushed toward booking and misrepresented the caring, guided conversation. They approved keeping all five lead choices and labeling the mid-conversation excerpt rather than rewriting its opening.

**How to apply:** Keep future marketing demonstrations faithful to real flow transitions. Emphasize different wording by a past patient's service versus an incoming lead's campaign/offer. Do not imply the two products use identical scripting or claim a generic sample represents every niche.

name: Strategy-call marketing funnel
description: User requirements for the dedicated Patient Pipeline strategy-call marketing page and audience gate.
---

Keep the dedicated marketing landing page focused on scheduling a strategy call: logo and scheduling CTA, headline, subheadline, full four-minute walkthrough, CTA, about four features, and footer. Do not add Home, How It Works, or Client Login links to this funnel.

**Why:** The user explicitly requested a simple marketing-only page without those distractions, using the existing brand.

**How to apply:** Preserve that scope when revising the dedicated landing and its form page. This restriction is not a request to remove navigation elsewhere in the app.

The patient/provider selection must send providers to the existing practice booking form and patients to a providers-only rejection page.

**Why:** The user said, “Say that it's only for providers and just send them to a rejection page.”

**How to apply:** Do not offer patients the strategy-call form or create a patient-care scheduling flow within this funnel.

On the strategy-call schedule form, the user expects gray example text inside the first name, last name, email, and practice name inputs, matching the phone, ZIP, and inactive-files inputs. Keep the separate visible labels above those fields as well.

**Why:** The user pointed to a screenshot and clarified that the blank input interiors were the missing guidance; checking only the labels above the fields missed their concern.

**How to apply:** When revising this form, check both persistent external labels and the in-field examples on desktop and mobile.

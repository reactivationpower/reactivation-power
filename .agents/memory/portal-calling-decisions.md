---
name: Portal calling decisions
description: User-selected billing model for proposed optional Twilio calling in Patient Pipeline.
---

For the proposed optional portal-calling feature, each practice should connect or create its own Twilio account and pay Twilio directly for calling usage.

**Why:** The user explicitly selected direct Twilio billing rather than Patient Pipeline-managed usage billing.

**How to apply:** Scope customer-owned account onboarding, not parent-account subaccounts billed to Patient Pipeline. This choice does not authorize implementation, set a separate feature price, or settle caller ID, recording, or mobile calling behavior.
